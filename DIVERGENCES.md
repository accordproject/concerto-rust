# Divergences

Differences from the TypeScript reference that the port keeps on purpose. See
PORTING.md section 7.3 for the categories and the rules for adding a row.

**Class-not-message parity (maintainer decision 2026-09-27, task P5-09,
accordproject/concerto-rust#253; PORTING.md section 2).** Rust must throw in
the same scenarios as TS with the same exception class; the message text may
differ. A row whose only difference from TS, or from the "expected elsewhere"
behaviour, is exception message text is therefore **superseded by this
policy**: it is kept for history, marked below, and no longer constrains the
port. Rows that differ in class, in whether an error is thrown, or in a value
stay in force. Superseded: DV-001, DV-016.
